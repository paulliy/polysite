# About

I'm Paul - I build software products end to end, with a soft spot for
interfaces that behave like machines you can hear thinking.

This site is rendered as a single fixed grid of split-flap characters,
like a train station departure board. There is no page scroll anywhere:
wheel, swipe, and arrow keys page through frames of content, and only
the characters that change between frames flip.

## Colophon

Vue 3, TypeScript, Vite, and JetBrains Mono. The flip engine, pagination,
and image dithering are plain TypeScript modules with unit tests; the
animation is CSS 3D transforms - no animation library.
